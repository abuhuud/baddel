Pengaturan Publikasi GitHub & Vercel

Server-Side Token Aktif

Token GitHub Anda telah disimpan secara aman di backend server Vercel (api/publish.js). Pengunjung web tidak dapat melihat atau mengakses token ini. Anda dapat langsung mengklik PUBLISH VERCEL dari perangkat mana pun.

Kosongkan jika menggunakan token bawaan server Vercel. Isi hanya jika Anda ingin mengganti dengan token baru.

Cara Membuat GitHub Personal Access Token (1 Menit)

  1. Buka GitHub Settings Tokens ↗ di tab baru.
  2. Klik Generate new token (classic).
  3. Beri Note: Baddel CMS Publish, lalu centang scope repo (Full control of private repositories).
  4. Scroll ke bawah dan klik tombol hijau Generate token.
  5. Salin token (dimulai dengan ghp_...) lalu tempel ke kolom token di atas dan klik Simpan Pengaturan.

Ekspor & Backup Database

Simpan backup data atau download file data.js terbaru untuk disimpan langsung ke repo GitHub.

Download updated data.js

Karena situs ini bersifat statis di GitHub Pages, Anda dapat mendownload file data.js yang sudah diperbarui dan menaruhnya di folder js/data.js untuk dijadikan commit permanen di repository GitHub.

JSON Backup / Restore

Salin data JSON lengkap atau tempel JSON untuk merestore data ke browser ini.
